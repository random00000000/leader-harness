# PATTERN - Voice And Tone

## Intent

> "It should be a harness for people to use aimed for leaders to recieve briefings but it should not be "toy" like in the language. It should be serious and aimed so it is almost like an intelligence agency for people to use and shape so it should not be "game like" or toy like in that regard it should be serious and aimed to be used by executives with not much time to spare."

See the [[PROMPT-LEDGER]] row dated 2026-09-25.

## The standard

Leader Harness should read like an intelligence service or an executive office: calm, precise and brief. Every word shown to the Leader, and every prompt sent to an Official, follows this page.

- **Brevity first.** Bottom line up front, short sentences, no filler, no exclamation marks, no jokes, no emoji in the product.
- **Institutional, not theatrical.** Use terms from real briefing practice (classification, precedence, minute, submission, decision memo). Avoid game, fantasy or roleplay language.
- **Visual restraint.** Flat surfaces, straight lines, real document conventions (for example, classification banners at the top and bottom of a page). No rotated stamps, paperclips, fake device status bars or heraldry.
- **The Leader's time is the scarce resource.** Every screen answers "what do I need to know, and what do I need to decide?"

## Vocabulary

| Use | Never |
|---|---|
| Leader | player, commander |
| Senior Official, Officials | cabinet, ministers, marshals, generals |
| Appoint / Remove an Official | spawn, hire, dismiss, fire |
| Briefing | report card, update feed |
| Decision, decision request | event, popup, quest |
| Instruction ("Send instruction") | order, command, directive (in the UI) |
| Surge (a concentrated effort on one objective) | big push, campaign, offensive |
| Halt work / Resume work | kill, freeze |
| Project Lead, Chief of Staff, Director of Research, Head of Engineering | Minister, Quartermaster, Marshal |
| Monogram (the Official's initials) | emblem, shield, crest |
| Dispatch (the corner panel that brings briefings to the Leader) | inbox, feed, notifications center |

Built-in style names: **Slide Deck**, **Dossier**, **Red Box**, **Daily Brief**, **Daily Brief (Night)**.

The classification levels ROUTINE / PRIORITY / FLASH stay. They are real precedence markings.

## Decisions

- The origin story (briefing styles first built for a strategy game) is history. It may appear in the wiki's history, but never in the product, the prompts, or the README (DECISION, 2026-09-25).
- Internal code identifiers (`operation`, `directive`) keep their names; only text people see follows this page. Revisit if the mismatch confuses contributors.

## Tried and rejected

- The Hearts of Iron-style event popup (ornate gold frame, striped banner, heraldic shield), the rotated CONFIDENTIAL stamp and paperclip on the dossier, fake tablet status bars, and game-flavoured names such as "Marshal Ardent" and "Minister for the Game". The human judged them "toy like" on 2026-09-25.
